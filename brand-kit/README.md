# Vaultrush brand kit

Master files of the logo and icons (made 2026-11-25). The files the site actually serves are in `public/`:

| Served file | Use |
|---|---|
| `public/brand/logo-dark.svg` | The wordmark in the sidebar, the log-in window and the maintenance screen |
| `public/brand/mark.svg` | The V mark alone: the phone header |
| `public/brand/social-card.jpg` | The 1200 × 630 picture shown when a link to the site is shared |
| `public/favicon.ico`, `public/favicon.svg`, `public/apple-touch-icon.png`, `public/icon-192.png`, `public/icon-512.png`, `public/site.webmanifest` | Browser tab, home-screen and app icons |

The twelve menu icons are drawn inline from `ICONS` in `src/ui.ts` (same shapes as `icons/` here), so they follow the text colour. The V mark on the loading screen is inline in `index.html`.

Kept here for later use, not served: `logo-light.svg` (pale backgrounds), `logo-white.svg`, `logo-dark.png`, `app-mark.svg`, `sprite.svg`, `icons/`, `icon-16/32/48.png`, `preview.png` (overview sheet).

Colours: lime `#CBFA3D` (the site's accent is `#c6ff3d`, close enough to read as the same), navy `#101625`, cream `#F6F4EA`.
